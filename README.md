# 전자전 중 EA의 위험성 — 웹 기반 재밍 시연 교육자료

최종 갱신: 2026-11-03 · 시연 버전 v0.2

학부 3학년 전자전공 학생에게 전자공격(EA)의 효과를 **수식과 함께 눈·귀로** 보여주는 브라우저 시연 자료입니다.
대상 4종(음성 통신 · GNSS · 탐색 레이더 PPI · SAR 영상) × 재머 2종(잡음 · 기만), 한 바퀴 약 15분.

> 공통 교훈: 재밍 효과는 **수신기에서의 J/S**가 임계값을 넘어야 나고, J/S를 키우는 길은 **출력을 올리거나 거리를 줄이는 것**뿐이다.
> 단방향(통신·GNSS)은 재머에게 유리하고, 양방향 레이더(R⁴)는 불리해서 burn-through가 생긴다.

---

## 실행 방법

1. `web/index.html`을 크롬으로 엽니다 (더블클릭, 인터넷 불필요).
2. 시작 화면에서 모듈 카드를 고르거나 **시연 시작 — 통신부터**를 누릅니다.
3. 각 페이지 상단의 **시연 단계** 버튼을 왼쪽부터 차례로 누르면 발표 장면이 그대로 재현됩니다.
   슬라이더를 직접 만져도 됩니다.
4. 통신 모듈은 **재생**을 눌러야 소리가 납니다. 한국어 TTS 음성이 설치된 PC가 필요하며
   (Windows·Mac 기본 포함), 없으면 내장 합성음으로 자동 대체됩니다.
   진짜 교신·가짜 지시 녹음 파일(WAV/MP3)을 올리면 그 음원을 씁니다.

## 모듈별 핵심 장면

| 모듈 | 수식 | 잡음 재밍 | 기만 재밍 |
| --- | --- | --- | --- |
| 통신 | 링크 방정식 (단방향) | 음성에 잡음, FM 포획 효과로 두절 | 좌표 구간에만 가짜 좌표 삽입 |
| GNSS | 링크 방정식, 위성 링크 고정 | 저앙각 위성부터 끊겨 NO FIX | 항법 화면은 정상, 실제 차량은 금지구역 진입 |
| PPI | 레이더 방정식 (R⁴) | 스트로브에 묻혔다가 burn-through 안에서 재출현 | 거리 기만(RGPO) / 방위 기만(부엽) |
| SAR | 레이더 방정식 + 처리 이득 | 처리 이득 때문에 큰 출력 필요 | DRFM 복제본이 처리 이득을 받아 mW로도 거짓 차량 |

## 시연 순서 (약 15분)

시작 화면에도 같은 표가 있고, 각 페이지의 **시연 단계** 버튼이 이 순서대로 배치되어 있습니다.

| # | 대상 | 장면 | 전달 포인트 |
| --- | --- | --- | --- |
| 1 | 통신 | OFF 교신 청취 → ON(1 W·150 km)인데 그대로 → 출력 50배 → 두절 | 켜는 것만으로는 안 된다. J/S 임계값과 FM 포획 효과 |
| 2 | 통신 | 출력은 1 W, 거리만 40 km → 같은 두절 → 기만, 좌표 구간 삽입 | 출력과 거리는 같은 레버. 기만은 경고가 없다 |
| 3 | GNSS | 1 W 재머를 15 km → 8 km로. 임계선이 올라가며 NO FIX | 같은 수식, 위성 신호가 약해 수 W로 끊긴다 |
| 4 | GNSS | 스푸핑 10 mW. 실제 상황을 가린 채 항법 화면만 보여주고 질문 → 공개 | 스푸핑은 전력이 거의 필요 없고 화면으로는 알 수 없다 |
| 5 | PPI | 10 W 자체보호 재머에 1 MW 레이더가 표적 상실 → 접근 → burn-through | 레이더는 R⁴, 재머는 R². 여기서는 재머가 불리 |
| 6 | PPI | 거리 기만(RGPO) → 같은 출력으로 방위 기만 → 실패 → 출력 ×1000 | 부엽을 거치면 약 30 dB 더 필요 |
| 7 | SAR | 잡음 10 W 무효 → 1 kW에서야 식별 불가 → DRFM 10 mW로 거짓 차량 | 잡음은 처리 이득을 못 받고, 복제 신호는 받는다 |

마무리: 네 수식 패널을 나란히 놓고 "단방향 둘은 먼저 무너지고 양방향은 버틴다"를 한 문장으로 정리합니다.

## 진행 이력

1. 연구 방향 설정: 학부 3학년 전자전공, 시연 중심, 4개 대상 × 잡음/기만.
2. 시작화면·시연화면 설계 시안 (캔버스).
3. 통신 모듈: 링크 방정식, 상황도, 통신 가능 거리 원, 재머 효과 반경, 수신 전력 미터·SNR/SINR, TTS + 잡음 혼합, 좌표 구간 기만.
4. GNSS 모듈: 평면도·단면도(앙각 배치, 안테나 패턴), 위성별 C/N₀, 측위 오차·궤적·시간 그래프, 이동 시나리오.
5. PPI 모듈: 고정 레이더·접근 항공기, PPI/A-스코프, burn-through, 자체보호/지원 재머, 거리 기만·방위 기만.
6. SAR 모듈: 토지피복 분류 + 반사계수 + 스펙클 합성 영상, 처리 이득 모델, 잡음/DRFM 기만, 원본 vs 재밍 비교.
7. 제안서(PRD) 작성.
8. **v0.2 (2026-11-03)** — Claude Code로 핸드오버. 오프라인 시작 화면 신설, 네 모듈에 공통 발표 도구
   (시연 단계 버튼 · 단축키 · 테마 전환) 주입, 오프라인/온라인 두 벌을 빌드로 통합, 오타·일관성 수정.
9. **배포 준비 (2026-11-03)** — 배포 대상 폴더를 `web/`, 파일명을 ASCII로 정리(주소 길이 때문).
   제안서 docx는 저장소에서 제외하고 요구사항을 `PRD.md`로 옮김. git 저장소 초기화.
