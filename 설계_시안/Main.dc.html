전자전 중 EA의 위험성

재머 종류(잡음·기만)와 대상(대역별 통신·SAR 영상)을 고르고 통신 방정식·레이더 방정식의 파라미터를 조작하면, 전자공격이 통신 품질과 SAR 영상을 어떻게 무너뜨리는지 화면에서 바로 확인합니다. 설치 없이 웹 브라우저에서 실행되는 시연 버전입니다.

대역별 통신 (음성)

통신 링크 방정식으로 J/S를 계산하고, 음성 교신에 잡음이 섮이거나(잡음) 가짜 음성으로 바뀝는(기만) 것을 직접 들습니다.

  • HF·VHF·UHF 대역 선택
  • 재머 출력·거리·대역폭
  • AM/FM 포획 효과 임계값

  • 안테나 이득·RCS·거리
  • burn-through 거리

SAR 영상

레이더 방정식에 펄스 압축·합성 개구 이득을 더해 영상 SNR을 구하고, J/S가 커질수록 영상이 열화되거나 거짓 표적이 생기는 과정을 봅니다.

  • 처리 이득 항 표시
  • 원본 vs 재밍 영상 비교
  • DRFM 거짓 표적

시뮬레이션 모델

통신·GNSS는 단방향 링크 방정식, PPI·SAR은 양방향 레이더 방정식으로 J/S를 계산합니다. 같은 재머를 네 대상에 적용해 단방향 링크가 재머에게 얼마나 유리한지 수치로 비교할 수 있습니다.

조작 가능한 변수

수식에 나오는 변수를 그대로 슬라이더로 노출합니다: 송신·재머 출력, 안테나 이득, 주파수(대역), 거리, 대역폭, RCS, 처리 이득, 기만 유형. 값을 바꾸면 수식의 숫자와 화면이 동시에 갱신됩니다.

실행 환경

Python(NumPy) 모델을 웹 UI로 감싸 Chrome 등 브라우저에서 링크 하나로 열립니다. 각 대상은 독립적으로 열 수 있어 발표 시간에 맞춰 일부만 시연할 수 있습니다.
